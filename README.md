# EthernetIPRust

Idiomatic async Rust implementation of EtherNet/IP + CIP, focused on communicating with
Allen-Bradley Logix controllers.

Sibling of [EthernetIPCpp](../EthernetIPCpp), [EthernetIPSharp](../EthernetIPSharp), and
[EthernetIPPython](../EthernetIPPython). Same wire behavior, Rust API.

## Status

Scaffold — see the other repos for the reference implementation while this port catches up.
